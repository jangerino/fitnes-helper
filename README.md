# Fitness Helper

Fitness Helper — это веб-приложение на Flask для расчета:

- суточной нормы калорий
- белков, жиров и углеводов (БЖУ)
- количества воды

Пользователь вводит:
- вес
- рост
- возраст
- пол
- цель

После чего приложение рассчитывает персональные показатели.

---

# Технологии

- Python 3
- Flask
- HTML5
- CSS3
- JavaScript
